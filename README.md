# LSTMPredictor for Time Series Prediction

This repository contains an implementation of an LSTM-based predictor using PyTorch for time series prediction. It generates synthetic sine wave data and trains an LSTM model to predict future values.

## Code Overview

- **Data Generation**: Generates synthetic sine wave data with noise.
- **Model Architecture**: Uses two LSTM layers followed by a linear layer for prediction.
- **Training**: The model is trained to predict future values based on input sequences.
- **Visualization**: Includes a plot showing the generated sine wave.

## Requirements

- Python 3
- PyTorch
- NumPy
- Matplotlib

## Usage

1. Run the script: `python main.py`
